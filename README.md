# TheStation | ذا ستيشن 🎙️🎬📝

**TheStation (ذا ستيشن)** هي منصة وأدوات إنتاج المحتوى الرقمي والإعلامي المصممة خصيصاً لصُنّاع المحتوى باللغة العربية. توفر المنصة نظاماً شاملاً لإدارة كتابة السكربتات، البحث وتفريغ مقاطع يوتيوب مع أداة تحديد المقاطع والأجزاء، البحث عن الصور عالية الدقة الخالية من حقوق الملكية، وتحويل النصوص إلى قراءة صوتية باللكنة السعودية.

---

## 🌟 المميزات الرئيسية (Key Features)

### 1. 🏠 لوحة التحكم والتحليلات (Dashboard)
- **إحصائيات السكربتات التفاعلية:** متابعة فورية لأعداد السكربتات المكتوبة (🟡)، الجاهزة (🟢)، والملغاة (🔴).
- **الإجراءات السريعة (Quick Actions):** إنشاء سكربت جديد، البحث السريع في يوتيوب والصور، وتوليد التعليق الصوتي بضغطة زر.
- **سجل البحث الأخير:** عرض أحدث عبارات البحث في يوتيوب ومكتبات الصور.

### 2. 📝 إدارة السكربتات والمحرر الاحترافي (Script Management & Editor)
- **نظام الحالات الصارم (Status System):**
  - 🟡 **سكربت مكتوب (WRITTEN):** تحت الكتابة والتنقيح.
  - 🟢 **سكربت جاهز (READY):** مكتمل وجاهز للتسجيل والنشر.
  - 🔴 **سكربت ملغي (CANCELLED):** سكربت ملغى أو مستبعد.
- **تصفية وبحث فوري:** تبويبات تصفية مع عدادات ديناميكية محدثة لحظياً، وبحث في العناوين والمحتوى مع دعم التثبيت (Pin)، التكرار (Duplicate)، والحذف.
- **محرر نصوص غني (Rich Text Editor):** يدعم التنسيقات (غامق، مائل، عناوين، قوائم، محاذاة النص، تراجع/إعادة) مع زر مخصص لإضافة مدّ التطويل العربي (ـ).
- **حفظ تلقائي وعدّاد كلمات:** حفظ تلقائي مستمر مع حساب عدد الحروف، الكلمات، وتقدير زمن القراءة.

### 3. 🎬 البحث وتفريغ مقاطع يوتيوب (YouTube Tool & Workspace)
- **بحث يوتيوب المباشر:** استعراض نتائج مقاطع الفيديو مع الصور المصغرة، أسماء القنوات، المدى الزمني وعدد المشاهدات.
- **مساحة عمل الفيديو (Video Workspace):** مشغل فيديو يوتيوب مدمج مع تحكم كامل.
- **أداة تحديد الأجزاء والفقرات (Section Selector):**
  - التقاط وقت البداية والنهاية تلقائياً من موضع التشغيل الحالي (`setStartFromCurrent` / `setEndFromCurrent`).
  - حساب المدة الزمنية للفقرة المختارة تلقائياً.
  - معاينة الجزء المحدد في حلقة تكرارية.
  - مشاركة وتصدير رابط التوقيت المباشر للمقطع.

### 4. 🖼️ بحث الصور والمعاينة (Image Search & Gallery)
- **مكتبة صور احترافية:** شبكة صور تفاعلية (Masonry Grid) تعرض دقة وأبعاد الصور ومصدرها.
- **نافذة معاينة مكبرة (Preview Modal):**
  - تنزيل الصورة مباشرة بصيغة عالية الدقة.
  - نسخ رابط الصورة المباشر.
  - فتح المصدر الأصلي في تبويب جديد.

### 5. 🎙️ تحويل النص إلى صوت باللكنة السعودية (Saudi Arabic Text to Speech)
- **محرك صوت سعودي مجاني ومعتمد:** يعتمد على `Web Speech API` المدمج في المتصفحات لدعم القراءة باللغة العربية واللكنة السعودية (`ar-SA`) مجاناً 100% ودون الحاجة لمفاتيح خارجية.
- **تحكم متكامل:** خيارات التحكم في السرعة (0.75x, 1.0x, 1.25x, 1.5x) ونبرة الصوت (Pitch).
- **شاشة تشغيل تفاعلية:** موجات صوتية متحركة أثناء القراءة مع إمكانية إيقاف وإعادة التشغيل.
- **ربط التعليق الصوتي بالسكربت:** ربط الملاحظات الصوتية والتعليقات بالسكربتات الموجودة في قاعدة البيانات.
- **سجل التحويلات الصوتية:** حفظ واسترجاع التحويلات الصوتية السابقة.

### 6. ⚙️ الإعدادات والنسخ الاحتياطي (Settings & Backup)
- **النسخ الاحتياطي الكامل:** تصدير واستيراد جميع البيانات والسكربتات بصيغة `JSON`.
- **مفاتيح API الاختيارية:** إضافة مفاتيح Google YouTube API أو Pexels/Unsplash لتوسيع حدود البحث.

## 🛠️ التقنيات المستخدمة (Technology Stack)

- **Frontend:** HTML5, Modern CSS3 (Variables, Dark SaaS Theme), Vanilla JavaScript (ES6+ Modules).
- **Typography:** Google Fonts (`Cairo`, `Tajawal`) مع دعم كامل للاتجاه من اليمين لليسار (`dir="rtl"`).
- **Data Persistence:** IndexedDB API + LocalStorage Fallback (قاعدة بيانات محلية سريعة ودائمة).
- **Audio Synthesis:** Web Speech API (`SpeechSynthesis` with `ar-SA` support).
- **Video Player:** YouTube IFrame Player API.
- **Mobile Packaging:** Capacitor 6.0 (بناء تطبيق أندرويد APK).
- **CI/CD:** GitHub Actions (Deploy to GitHub Pages & Build Android APK).

## 🤖 بناء وتحديث التطبيق تلقائياً (GitHub CI/CD)

يحتوي المستودع على سير عمل أوتوماتيكي عبر **GitHub Actions**:
1. **نشر موقع الويب تلقائياً على GitHub Pages:** `.github/workflows/deploy-pages.yml`
2. **بناء ملف APK للأندرويد تلقائياً:** `.github/workflows/build-apk.yml`

يمكنك تحميل ملف الـ **APK** لنظام الأندرويد من تبويب **Actions** في GitHub تحت قسم **Artifacts**.
